# 🎭 Fora de Cena — Cultura &amp; Eventos no Porto
&gt; **Projeto Final de Programação Web — CESAE Digital**  
&gt; Um site completo, moderno e responsivo para dar visibilidade tanto a grandes produções culturais como a pequenos eventos independentes e locais na cidade do Porto.

## 📌 Visão Geral do Projeto

O **"Fora de Cena"** nasceu com o propósito de democratizar o acesso à cultura no Porto. A plataforma reúne numa só agenda os grandes espetáculos das salas de referência (como o Coliseu ou o Rivoli) e os pequenos eventos independentes de teatro de bolso, dança contemporânea e música local que muitas vezes passam despercebidos.

Este projeto foi desenvolvido como **trabalho de avaliação final do módulo de Programação Web**, cumprindo rigorosamente os requisitos de HTML5 semântico, responsividade com Bootstrap 5.3, CSS customizado e programação orientada a eventos com Vanilla JavaScript.
